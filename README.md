# Persona 3 Inspired Portfolio

A single-page portfolio website inspired by the iconic UI aesthetics, high-contrast colors, and dynamic motion of Persona 3. Built and sliced using Kiro IDE to showcase web development projects, technical skills, and creative front-end design.

---

## Features

* **Persona 3 UI Aesthetics**: Styled with high-contrast blue/cyan palettes, bold typography, dynamic gloss, and glassmorphism elements.
* **Interactive Navigation**: Seamless single-page scrolling experience mimicking game menus.
* **Featured Projects Showcase**: Grid layout displaying web apps, embedded projects, and front-end experiments.
* **Responsive Layout**: Optimized for mobile, tablet, and desktop viewports.
* **Fast & Lightweight**: Clean component structure for rapid loading times and smooth performance.

---

## Tech Stack & Development Tools

* **IDE / Editor**: Kiro IDE
* **Front-End**: HTML5, CSS3 / Tailwind CSS, JavaScript (ES6+)
* **Deployment**: GitHub Pages
* **Design & Layout**: Custom UI Slicing & Responsive CSS
